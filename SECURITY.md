# Security policy

Software Dark Factory is a Developer Preview. Please do not file a public
issue for a security concern that could expose users or repositories.

Report it privately to [johnnybutler7@gmail.com](mailto:johnnybutler7@gmail.com).
Include a clear description, affected version or commit, reproduction steps or
a proof of concept where safe, expected and observed behaviour, and any known
impact or mitigations. There is no guaranteed response SLA during the preview.

SDF runs repository-configured verification commands with your local
permissions. Review those commands before executing them.
